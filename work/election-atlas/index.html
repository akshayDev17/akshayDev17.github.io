Election Atlas of India

Real
The 36 states and union territories, their boundaries, and how many Lok Sabha seats each returns — Uttar Pradesh 80, Maharashtra 48, and so on, 543 in all.
Not real
Which party won anything. The party-level seat splits, and every vote and elector figure, are placeholders: internally consistent, but not the published result. The colours on this map are therefore illustrative, not fact.
Derived, not stored
Result files hold absolute counts only. Which party leads each state — the one thing the map is coloured by — is computed in the browser as the page loads.
Boundaries
Drawn to India's official territorial claim, which reaches about 37°N: the parts of Jammu and Kashmir administered by Pakistan and the Aksai Chin area administered by China are shown as Indian territory. Boundaries come from the 2019 structure — Ladakh as its own union territory — via a public-domain file built by georeferencing Election Commission maps. Those borders are approximate, and a Survey of India source should replace them before anyone relies on them.
